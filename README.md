# NIGHT SHIFT

A browser-first low-poly survival horror game set inside Blackwood Facility.

## Run
Open `index.html` in a modern desktop browser. The game imports Three.js from jsDelivr, so the first load requires internet access.

## Controls
WASD movement · Mouse look · Shift sprint · E interact · F flashlight · C CCTV · Esc pause.

## Systems
Procedural low-poly facility, first-person controls, flashlight battery, facility power, CCTV camera network, generator faults, interactable documents/batteries/doors, entity state machine, random events, audio cues, six-plus night progression, death/results, settings and LocalStorage save data.

## Performance
LOW is the default: capped device pixel ratio, simple geometry/materials and limited dynamic lighting. MEDIUM/HIGH can be selected in Settings.

## Notes
The facility is generated procedurally at runtime so there are no heavyweight model downloads or static screenshots pretending to be gameplay.
